SQLScriptManage 使用說明

快速上手

先建立或選擇專案，再新增 SQL 腳本。編輯器內容會自動保存為草稿，完成後以「儲存新版本」建立可追蹤的歷史節點。

版本與分支

從任一歷史版本載入內容後繼續編輯並提交，就會以該版本作為父節點建立分支。載入版本不會刪除其他歷程。

快捷鍵與匯出

編輯器按 Tab 會插入兩個空白。可下載目前 SQL，或匯出完整 JSON 備份。備份匯入前會校驗結構並選擇合併或覆蓋。

資料保存

資料使用 IndexedDB 保存；若瀏覽器不支援，會暫存於記憶體，關閉分頁後資料會消失。
