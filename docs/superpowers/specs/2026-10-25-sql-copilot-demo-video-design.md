# SQL Copilot 4 分 30 秒 Demo 影片設計稿

## 目的

製作一支面向黑客松評審的繁體中文 4 分 30 秒提案 Demo 影片，說明 SQL SPA Tools 如何在本機分析合成 SQL 變更、由 M365 Copilot Chat 整理影響說明，再由工程師與風險覆核者依證據完成判斷。影片要呈現可檢查的原型流程與目前證據邊界，不把探索性演練說成正式驗收，也不宣稱未量測的效益。

## 目標與非目標

- 讓評審在 4 分 30 秒內理解業務痛點、操作流程、資料安全界線、解析限制、技術回歸證據與後續驗證計畫。
- 展示只使用 `DEMO_CUSTOMER`、`DEMO_MONTHLY_REPORT`、`DEMO_RISK_SEGMENTATION` 等合成物件及固定案例。
- 視覺以流程動畫、程式碼片段、介面重現卡片與 Copilot 回答示意構成；不把示意畫面冒充銀行正式環境截圖或實測回覆。
- 不製作正式環境操作教學、不連接資料庫、不上傳任何真實 SQL，也不把影片當作核准、治理或效益驗收證明。

## 方案比較與決定

1. **約 2 分鐘提案動畫**：重點集中，但無法忠實呈現正常案例、解析警告、技術證據與驗證規劃。未採用。
2. **4 分 30 秒 Demo 影片**：沿用既有逐段講稿，涵蓋正常與警告案例、人工安全檢查、測試證據及效益紀律。使用者已選定此方向。
3. **產品操作導覽**：介面步驟較多，但會弱化提案的風險管理主張與未驗證事項。未採用。

Remotion 專案預計放在 `參賽準備/sql-spa-tools-demo-video/`，不改動既有 SQL 工具。採 1920×1080、30 fps、270 秒、繁體中文畫面文字與旁白稿；沿用根目錄 `theme.md` 的石墨黑、冰川藍、雪霧白、暖磚橘與松針綠語意。除非後續另行要求，交付 Studio 可預覽的專案，不預設輸出 MP4。

## 視覺與聲音

- 畫幅 16:9、1920×1080、30 fps。畫面使用繁體中文，英文字段名與 SQL 型別保留原樣。
- 深石墨底承載程式碼與主標題，雪霧白提供閱讀區，冰川藍描繪資料關係；暖磚橘專用警告與人工確認，松針綠代表通過狀態並搭配文字標籤。
- 用簡潔節點線條、欄位卡片、JSON 摘要與 Copilot 對話卡片構成動畫；不使用真實客戶資料或未核准內部物件名稱。
- 旁白依現有 4 分 30 秒講稿修整為符合各段時長的口語稿，使用沉穩、清晰的合成繁體中文語音。字幕需涵蓋主要敘事與數字。音樂若加入，使用低音量、不干擾旁白的素材。
- 不在畫面中杜撰 Copilot 輸出內容。凡非產品實際畫面的 UI 示意皆須加上「示意」標記；30 項測試與 1,000 筆 prepared 等數字保留來源與限制註記。

## 驗收條件

- Remotion Studio 可載入單一 Demo composition，總長精確為 270 秒，時間段落與講稿一致。
- 各場景的繁體中文字可讀、無關鍵裁切，色彩遵循 `theme.md` 的語意規則。
- 合成正常案例的兩個預期影響、警告案例的限制、30 項通過與 1,000 筆 prepared 的區別均正確。
- 全片沒有把銀行核准租用戶、Copilot 附件流程、效益節省或正式環境適用性說成已完成驗證。
- 先交付可互動預覽；僅在使用者明確要求匯出時才渲染最終影片。

## 留給製作者的決定

使用既有講稿與提案報告作為事實來源；若文字長度與鏡頭時長衝突，先縮短語句，不刪除限制揭露。可用實際本機工具介面截圖作畫面素材，但必須標示為合成案例的原型畫面；否則使用自製示意 UI。所有旁白、音樂素材和字幕處理方式應在製作階段確認可用性與呈現方式。
